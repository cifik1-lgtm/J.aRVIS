## 🚀 Installation & Setup
1. **Requirements**: Windows 10/11, Python 3.12+, and an RX/RTX GPU.
2. **Setup**:
   ```bash
   pip install -r requirements.txt
   playwright install
   ollama pull qwen2.5-coder:7b
   ollama pull mistral:7b
   ollama pull hermes3:8b
   ```
3. **Launch**:
   ```bash
   python main.py
   ```
